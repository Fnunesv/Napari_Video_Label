# 6. Condition label

A static free-text label (e.g. a construct or condition name) burned into
every frame, independent of phase/time.

| Field | Meaning |
|---|---|
| Show condition label | Toggle on/off |
| Text | Free text, e.g. `CRY2-mCherry` |
| Anchor corner | Which corner the label is placed relative to |
| Offset from corner (px) | X/Y distance inward from the anchor corner |
| Font size | Relative scale |
| Font color | Click the swatch to open a color picker |
